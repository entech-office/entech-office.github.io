# entech-office

公開中的企業網站原始碼，由 GitHub Pages 從 `main` 分支根目錄部署。

## 現況

網站目前為第一版。實際案例、課程與服務內容會在確認後再公開；不應將範例文案視為已提供的產品或實績。

## Structure

- `index.html`、`courses.html`、`member.html`：靜態頁面
- `styles.css`、`site.js`：網站樣式與互動
- `logos/`：公開使用的品牌 logo

Courses

会計業務の自動化を、
つくれるところまで学ぶ。 把會計流程自動化，
學到能自己做出來。 Learn accounting automation
until you can build it yourself.

題材は実際の会計・財務業務。業務の分解からフロー設計、ツールでの実装、そして運用までを、初級・中級・上級の3段階で扱います。単堂で完結する講座と、複数回で組み立てるコースを用意しています。 題材是實際的會計財務業務。從流程拆解、流程設計、工具實作到後續維運，分初級、中級、進階三級。有單堂就能完成的課程，也有需要多堂組裝的完整課程。 The material is real accounting work: breaking the process down, designing the flow, implementing it in a tool, then running it. Three levels — single-session classes, and multi-part courses you assemble over several sessions.

01 — Single sessions

単堂講座單堂課程Single classes

1 回で完結する講座。業務のどこを自動化するか決めるところから、実際に手を動かすところまでを 1 テーマに絞っています。一堂就能完成的課程。從判斷「流程的哪一段該自動化」到實際動手做，每次只聚焦一個主題。Classes that stand alone. Each one narrows to a single theme — from deciding which part of the process to automate, to actually building it.

会計業務の棚卸しと、自動化候補の見つけ方會計流程盤點與自動化切入點Mapping accounting work to find what to automate

02 — Levels

レベルの定義程度定義How the levels work

3 段階は「ツールの操作習熟度」ではなく「何を自分で決められるか」で分けています。会計実務の経験は Lv.1 の前提条件ではありません。三級不是按「工具操作熟練度」分，而是按「你能自己決定什麼」分。會計實務經驗不是 Lv.1 的前提。The three levels are split by what you can decide on your own, not by tool fluency. Prior accounting experience is not a prerequisite for Lv.1.

Lv.1

見つけられる找得出來Can spot it

自分の業務のどこが自動化候補か、説明できる状態。ツールの前提知識は不要。能說明自己流程的哪一段適合自動化。不需要工具先備知識。You can point at which part of your own work is automatable. No tool knowledge needed.

Lv.2

つくれる做得出來Can build it

ひとつのフローを最後まで組み、例外が出たときに止められる状態。基本操作の経験を想定。能把一條流程從頭組完，出例外時知道怎麼停。預設有基本操作經驗。You can build one flow end to end and stop it when an exception shows up. Basic tool experience assumed.

Lv.3

もたせる維得下去Can keep it running

作った仕組みを、人が入れ替わっても維持できる設計にできる状態。判断は設計の話。能把做出來的機制設計成「換人也能維持」。重點在設計判斷。You can design what you built so it survives staff turnover. This level is about design judgement.

02

受講で得られること上完能帶走什麼What you leave with

3 点まで。動詞で書く（「〜できる」）。ここが申込判断の中心。最多三點，用動詞寫（「能…」）。這是報名決策的核心。Three bullets max, each starting with a verb. This is where the enrolment decision happens.

04

対象者・前提知識適合對象與先備知識Audience & prerequisites
